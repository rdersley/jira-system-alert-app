# Nuvriqo Support — System Alert Manager

Nuvriqo provides support for current supported releases of System Alert Manager for Jira Service Management.

## Contact

Email: **support@nuvriqo.com**

When contacting support, include the app name, Jira Cloud site, app version shown in the System Alert Manager interface, and a description of the issue. Do not send passwords, API tokens, client secrets or other credentials in a support request.

## Support includes

- installation and configuration questions;
- investigation of suspected product defects;
- guidance on supported email and SMS provider configuration;
- Marketplace licensing and billing guidance where it relates to System Alert Manager;
- clarification of documented product behaviour.
