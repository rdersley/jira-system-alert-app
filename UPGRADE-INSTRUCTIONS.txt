System Alert Manager v3.9.2 upgrade

1. Copy/extract this release over the existing registered Forge app folder.
2. Do NOT run forge register.
3. Run .\deploy-dev.ps1 from the app root.
4. No new Forge scopes or egress entries are introduced by v3.9.2.
5. Easy Connect requires vendor Forge environment variables MICROSOFT_MARKETPLACE_CLIENT_ID, MICROSOFT_MARKETPLACE_CLIENT_SECRET and MICROSOFT_MARKETPLACE_REDIRECT_URI before Connect can be used.
