System Alert Manager v3.7.7 upgrade

1. Extract this package over your existing GitHub-controlled app folder:
   C:\jiraapps\jira-system-alert-app

2. Build the alert UI:
   cd C:\jiraapps\jira-system-alert-app\static\alert
   npm install
   npm run build

3. Build the admin UI:
   cd ..\admin
   npm install
   npm run build

4. Build the issue panel:
   cd ..\panel
   npm install
   npm run build

5. Validate from the app root:
   cd C:\jiraapps\jira-system-alert-app
   npm install
   forge lint

6. If lint is clean, commit/push v3.7.7 to GitHub before deployment.

7. Deploy:
   forge deploy
   forge install --upgrade
   forge install list

No new Forge scopes are introduced by v3.7.7, so another major-version permission approval should not normally be required.

After deployment open System Alert Manager > Templates. Confirm the Branding, Initial Alert, Incident Update, Service Restored and Monthly Test sub-menu items load, then test Preview Email and Preview SMS before changing live wording.
