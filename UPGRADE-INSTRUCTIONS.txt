System Alert Manager v3.8.0 upgrade

1. Copy/extract this package over C:\jiraapps\jira-system-alert-app.
2. Build the Alert, Admin, and Panel UIs, or run deploy-dev.ps1.
3. Run forge lint before deploying.
4. v3.8.0 adds external egress for Microsoft login and Microsoft Graph. Forge may request a MAJOR_VERSION_RULE approval.
5. If requested, run:
   forge deploy --approve MAJOR_VERSION_RULE
   forge install --upgrade
6. Open System Alert Manager > General and verify the Jira field mappings.
7. Open Communication Providers, choose SendGrid or Microsoft 365, save the configuration, then send a test email.

Existing contacts, branding, templates, SendGrid/Twilio secrets, priorities, and monthly-test settings are preserved.
