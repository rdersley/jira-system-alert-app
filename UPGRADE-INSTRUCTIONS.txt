System Alert Manager v3.6.1 upgrade

1. Start from your committed v3.6.0 GitHub working folder.
2. Copy the contents of this package over the existing registered Forge app. Do NOT run forge register.
3. Build all Custom UI resources:

cd C:\jiraapps\jira-system-alert-app\static\alert
npm install
npm run build
cd ..\admin
npm install
npm run build
cd ..\panel
npm install
npm run build

4. Return to the app root and validate:
cd C:\jiraapps\jira-system-alert-app
npm install
forge lint

5. Commit/push to GitHub, then deploy:
forge deploy

No new Forge scopes are added by v3.6.1, so a new major-version approval should not normally be required.

6. Open System Alert Contacts. Confirm v3.6.1, client dropdown values, provider status, contact filtering and test buttons.
7. Edit each legacy contact once and select its Jira client so the contact stores the Jira option ID. Until migrated, legacy contacts continue to fall back to client-code matching.
